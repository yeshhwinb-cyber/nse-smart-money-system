# NSE Smart Money System

Institutional-grade NSE smart money trading and analytics platform.

## Features

- FastAPI backend
- PostgreSQL multi-schema architecture
- Sharekhan authentication lifecycle
- Live websocket engine
- Institutional participation analytics
- Smart liquidity analysis
- Sector rotation engine
- Market state classification
- Multi-stage screener promotion engine

## Tech Stack

- Python 3.14
- FastAPI
- PostgreSQL 18
- WebSocket
- Sharekhan API
